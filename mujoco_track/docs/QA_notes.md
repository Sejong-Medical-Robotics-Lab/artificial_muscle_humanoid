# 질의응답 정리 — 11/2 중간점검 발표자료 준비 중 나온 질문과 답

발표자료(`docs/…_최종.pptx`, 11/2 회의 최종본 19장)의 10월 신규 ①~⑥을 읽을 때 같이 보면 되는 설명. 수치는 `results/`의 json에서 나온 것이고, 다시 돌린
진단은 `src/diag/`에 있다. (우현수 교수 질문 → 정리, 2026-11-02)

## 1. "ID 토크"가 뭔가

ID = Inverse Dynamics(역동역학). 측정한 움직임(IK 관절각 → 속도·가속도)과 지면반력을 운동방정식에 넣어 "그 움직임을 만들려면 각 관절에
얼마의 토크가 있어야 했나"를 거꾸로 푼 값이다. 근육 모델 없이 운동학·질량·외력만으로 나오므로 설계의 기준 토크로 쓴다.
OpenSim ID 도구와 MuJoCo `mj_inverse`가 같은 일을 하고, 이 트랙에서는 둘을 같은 입력으로 비교했다(발목·무릎 0.5 % 이내).
"골반 잔차력"은 운동방정식이 안 맞을 때 골반(자유관절)에 남는 가짜 힘·모멘트 — 데이터·모델 일관성의 지표(% of peak GRF).

## 2. MJCF란

MuJoCo XML Format — MuJoCo가 읽는 모델 파일(`.xml`). URDF와 같은 역할이지만 `<tendon>`·`<actuator>`·`<equality>`·`<option>`까지 한 파일에 담는다.
이 트랙의 "변환"은 `.osim`(OpenSim 모델, 역시 XML) + 케이블 json → MJCF 자동 생성이다(`build_mjcf.py`). 골격은 `<body>` 중첩, 관절은
`hinge`/`free`, 무릎 종속축은 `<equality><joint polycoef>`, 케이블은 site + `<spatial>` 텐던 + `<general>` 액추에이터(이득 −F_max, 입력 0~1).
중력은 OpenSim 관례대로 Y 위(`gravity="0 -9.81 0"`)라 json 부착점을 변환 없이 쓴다.

## 3. "하네스를 달았다"는 뜻

골반에 단 가상의 보조 지지장치(재활 트레드밀의 체중지지 하네스, 휴머노이드 개발용 천장 크레인과 같은 역할). 구현은 골반 외력:
F = 1000·(기준 위치 − 현재 위치) − 150·속도 (yz 모드에서는 전진 x 성분 0), T = 200·(자세 오차) − 20·각속도. 강성 1000 N/m는 골반이
10 cm 내려가야 체중의 13 %를 받치는 정도라 "손잡이"이지 "크레인"이 아니다 — 그래서 하네스를 달고도 넘어진다(판정: 골반 < 0.6 m 또는 60° 기울기).
관절 토크는 100 % 케이블이 낸다. 하네스 힘을 체중(BW) 단위로 기록한 값이 "혼자 못 서는 정도"의 계기이고, 0에 가까울수록 자립 보행이다.
실물 테스트베드에서도 안전 하네스에 로드셀을 달면 같은 잣대가 된다.

## 4. RMSE 각도의 정확한 정의

제어 주기(10 ms)마다 다리 관절 8개(좌우 고관절 굴곡·내전·무릎·발목)의 현재 각도와 같은 위상의 기준 각도(사람 IK) 차이를 제곱해
관절·시간에 대해 평균하고 제곱근 → 도(°). 골반 6자유도는 제외. 3조건 그림은 관절별 RMSE의 산술평균, RL 평가는 전체 제곱평균(거의 같음).
읽을 때: (1) 지연이 있으면 대부분이 시간 오차다(무릎·발목이 300~400°/s로 움직이므로 0.1 s 늦으면 30~40°). (2) 성공 여부와 별개다 —
추종이 나빠도 걷고 좋아도 넘어진다. (3) RL 정책의 RMSE에는 균형을 위해 일부러 비킨 양(관절 목표 잔차 ±14°)이 섞여 있다.
감각: 토크 제어 휴머노이드 모션 모사·외골격 논문에서 5~10°가 흔하니 12~17°는 "패턴은 알아보지만 정밀하지 않은" 추종.

## 5. 동일 키 사람보다 30 % 가벼우면 성공률이 올라가나 (`mass_test.py`)

질량·관성 0.7배(65.7 → 46.0 kg), 8개 시작 위상, 3주기 상한, yz 하네스.

|---|---|---|---|---|---|
| 기준 1.0 | 0.99 s / 0/8 | 4 | 0.36 | 2.53 s / 3/8 | 0.27 BW |
| C 균일 0.7 + 피드포워드·PD·강성·하네스 0.7배 (= 힘 1.43배 등가, 공정 비교) | 0.92 s / 0/8 | **0** | **0.28** | 2.36 s / 3/8 | 0.29 BW |
| A 균일 0.7, 제어기 그대로 | 1.27 s / 0/8 | 2 | 0.33 | 2.90 s / 6/8 | 0.40 BW |
| B 균일 0.7, 피드포워드만 0.7배 | 1.21 s / 0/8 | 4 | 0.33 | 2.84 s / 6/8 | 0.35 BW |

결론: 힘·열 문제(포화·듀티)는 확실히 풀리지만 완주율은 그대로. 질량은 걷기의 시간 척도(√(L/g))를 바꾸지 못해 열지연·균형 문제가 그대로이기
때문. A/B/D의 6/8은 하네스가 상대적으로 43 % 세진 효과(절대 힘 ~210 N 동일)와 감속(0.90 → 0.44~0.70 m/s)의 몫. 시뮬에 없는 실물 이점:
필요 힘이 줄면 도달 온도가 낮아져 가열·냉각이 빨라지고 듀티 0.28은 공랭 상한 0.35 안.

## 6. 잔차 RL을 해도 절뚝이는 이유와 개선 순서

진단: (1) 기준 위상이 시계로만 돌아간다 — 정책은 0.5 m/s로 걷는데 기준은 1.27 m/s 박자라 스윙·지지가 어긋난다(영상에서 고스트가 앞서 감).
(2) 균형을 하네스가 잡는다(발 위치 조절 논리 없음, 하네스 벌점 0.3으로 부족). (3) 잔차 권한(±14°)과 학습량(1.2 M 스텝)이 "안 넘어지기"
수준. (4) 발목 밀어내기가 열지연에 늦고 무릎 신전 케이블은 여유 10 %라 포화.
개선 순서는 `plan_nov_walking.md`: 접촉 동기 위상 + 기준 속도 재조정 → 균형 피드백 → RL 환경 재설계·GPU 재학습 → 여유율·SES.

## 7. 이상 액추에이터인데 왜 못 걷나 · "1주기 완주"는 왜 썼나 (`diag/diag_ideal.py`)

"완주"는 틀린 말이었다. 넘어짐 판정(골반 < 0.6 m 또는 60°)이 1.05 s 안에 안 떴을 뿐, 골반은 0.89 → 0.73 m로 16 cm 가라앉았고 계속
걸리면 1.34 s(이상), 1.32 s(이상+SES), 1.09 s(SMA+SES)에 넘어진다. 회의 최종본(19장)은 이 정정 전 판이라 14장 표에 "완주"가 그대로 있다 — 읽을 때 "유지(넘어짐 판정 없음, 골반 −16 cm)"로 바꿔 읽을 것.
못 걷는 이유: 첫 지지(오른다리)는 잘 따라가지만 두 번째 지지(왼다리)에서 신전 케이블 M0·M1·M2·M7이 전부 상한에 붙는다(이상 조건에서도
8개 포화). 여유 10 %는 "사람과 똑같은 궤적·지면반력"일 때만 맞는 양이고, 폐루프에서는 작은 오차에도 더 필요하다. 골반이 내려가면
무릎 모멘트암이 커져 양의 되먹임. 여기에 균형 제어 부재, 시간 기반 위상, 피드포워드의 전제(사람 GRF) 불일치, 낮은 발목 이득(Kp 40, ZOH 안정 한계)이
겹친다. 이상 조건이 말해 주는 것은 "배치·배분으로 걷기 **모양**은 나온다"까지. "발목에 SES 병렬 강성이 필요하다"는 메시지는 유효.

장치: 힌지 1개(−100~+46°), 전완 1 kg + 말단 2 kg @ 0.30 m, 풀리 R25, 케이블 2개 길항, 활성 길이 150 mm(스트로크 60 mm), 예인장 0.40.

역학 F = K(ξ)(ε − 0.40ξ)⁺), 열 상한 u_max = (120 − T̂)/10. 모델 후보: (a) README 1차 열지연 + 선형 포화(파라미터 4), (b) 보강안 = 1차 + 가열/냉각

## 9. 영상에서 가운데 팔(README 모델)만 계속 흔들리는 이유 (`diag/elbow_why.py`)

냉각 시정수를 0.02 → 0.49 s로 바꿔도 진동이 안 사라진다(진폭 75 → 130° p-p) → 파라미터가 아니라 구조 문제. README 모델은 듀티가 조금만
바뀌어도 0.5 s 뒤 힘이 선형으로 바뀌는데, 하중 관성(~0.21 kg·m²)과 Kp 25로 고유진동수 ~1.7 Hz, 그 주파수에서 0.5 s 1차 지연의 위상 지연이
~80°라 이 PD로는 안정 여유가 없다 → 힘 포화·중력에서 멈추는 한계 진동. 실물과 보강안은 식는 동안 힘을 유지하는 히스테리시스 데드밴드가
작은 보정 명령을 흡수해 "걸쇠"처럼 멈춘다(정상 오차 3~5°는 그 뒷면). 실물 SMA에서 단순 PD가 되는 이유가 히스테리시스이므로, 히스테리시스
없는 모델로는 "불안정"이라는 틀린 결론이 나온다.
