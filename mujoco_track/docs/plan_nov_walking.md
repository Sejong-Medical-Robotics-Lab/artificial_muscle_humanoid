# 11월 보행 개선 계획 — "절뚝이는 잔차 RL"에서 "제대로 걷기"로

현재 상태(11/2): yz 하네스 보조 아래 잔차 RL 정책이 3주기(3.16 s)를 유지하지만 기준보다 느리게(0.5 m/s) 절뚝이며 걷고, 하네스를 떼면
1.1 s 안에 넘어진다. 명목 제어기는 어느 조건도 2주기를 못 넘긴다. 원인은 액추에이터 지연보다 **위상 비동기 · 균형 제어 부재 · 케이블 포화**다.
아래 순서대로 하고, 각 단계마다 같은 지표(생존 시간·완주율·RMSE·하네스 BW·전진 속도, 8개 시작 위상)로 전후를 비교한다.

## 1단계 — 접촉 동기 위상 + 기준 속도 재조정 (명목 제어기만, 1~2일)

* `walk_sim.Reference`의 위상을 시간이 아니라 **접촉 이벤트**로 진행: 뒤꿈치 접지(접촉력 > 문턱, 발 속도 < 문턱)에서 위상을 0 또는 0.5로
  재동기. 접지 사이에는 시간으로 진행하되 주기 추정치(최근 2걸음 평균)로 속도를 맞춘다.
* 기준 걸음을 액추에이터가 따라갈 수 있는 속도로: 1.27 m/s 궤적을 시간 스케일(×1.3~1.5 → 0.85~1.0 m/s)하거나 Uhlrich 데이터의 느린 trial이 있으면 그것으로.
  스케일 시 ID 피드포워드는 다시 계산(`id_replay.py`를 스케일한 IK로).
* 기대: 스윙/지지 어긋남 제거 → RMSE 하락, 넘어지는 시각 뒤로. 판정: 명목 제어기(SMA+SES)로 2주기 이상.

## 2단계 — 명목 제어기에 균형 피드백 (2~3일)

* 스윙 발 착지 위치를 골반 속도 오차로 조절(Raibert 휴리스틱 / capture point): Δx_foot = k·(v_pelvis − v_ref) + ½·v·T_stance.
  관절 목표는 발 위치를 역기구학으로 바꿔 `q_offset`에 넣는다(지금 RL 잔차가 쓰는 자리).
* 스윙 발 최소 높이 보장(발끝 높이 < 3 cm면 무릎 굴곡 목표 가산).
* 지지 다리 VMC(`walk_sim.WalkSim.vmc`)를 골반 높이 유지에 다시 시도(1차 시도는 효과 없었음 — 포화 때문일 가능성, 1단계 뒤 재평가).
* 판정: 하네스를 'yz' → 없음으로 바꿔도 2주기 이상.

## 3단계 — 잔차 RL 환경 재설계와 재학습 (연구실 GPU, 1주)

`rl_env.py`를 다음처럼 바꾼다.
* 관측 44 → +접촉 상태(2) + 발 위치·속도(골반 기준, 12) + 접촉 동기 위상(2) + 전 스텝 행동(24).
* 행동: 케이블 활성 잔차 16(scale 0.5 유지) + 관절 목표 잔차 8(scale 0.25 → 0.5 rad).
* 보상: 자세 0.3 + 속도 추종(전진) 0.3 + 골반 높이·자세 0.2 + 좌우 대칭·주기성 0.1 + 발 미끄럼·접촉 충격 벌점 + 활성 에너지 벌점 + 생존 0.3. 하네스 벌점은
  커리큘럼으로(초기 0.3 → 후반 1.0, 하네스 강성 1000 → 0).
* 참조 상태 초기화(RSI, 무작위 위상·속도)와 조기 종료는 유지. 외란(골반 외력 50~150 N, 0.2 s)과 질량·마찰·지연 무작위화 추가.
* 학습량 1.2 M → 30~50 M 스텝. CPU 2코어로는 1~2일이라 비현실적 → 연구실 5090 1대(SubprocVecEnv 64~128, `train_ppo.py`의 env 수만 변경)로 2~4시간.
  더 빠르게 하려면 MJX(GPU 병렬)로 환경 이식 — 케이블 텐던·접촉 구는 MJX가 지원.
* 판정: 8개 시작 위상 모두 3주기 유지, 하네스 없이 ≥ 5주기, RMSE ≤ 12°, 속도 ≥ 0.8 m/s.

## 4단계 — 설계 변수 (기계연·강병현랩과 결정)

* 케이블 힘 여유 1.3~1.6배(H5 모듈 배정) — 지지 다리 포화 제거. `mass_test.py` 조건 C가 "여유 1.43배"의 대리 실험.
* 무릎에도 SES 병렬 강성(발목 100 N·m/rad 수준) — `make_sim`의 `k_ankle` 처럼 `jnt_stiffness`로.
* 냉각 시정수(액랭) 0.13 → 더 짧게, 가열 0.12 유지 — `SMA(n, tau_h, tau_c)`.
